# Usage:
#   TSAN_OPTIONS="suppressions=$PWD/resple/test/tsan_suppressions.txt" <test-binary>

#
# History:
# - Phase 2.5 #2 (working_flag_mutex <-> search_rw_mutex_ lock-order
#   inversion): FIXED; its `deadlock:` suppressions were removed so a
#   regression fails the gate.

#   KD_TREE_NODE fields — father_ptr / range arrays / alpha_* pull-up writes
#   vs the rebuild's father_ptr read + swap ancestor Update-walk): FIXED.
#   working_flag_mutex is now recursive and the public mutators hold it
#   across their whole operation (see ikd_Tree.cpp start_thread /
#   ScopedPthreadLock). The former `race:multi_thread_rebuild` /
#   `race:multi_thread_ptr` suppressions were removed; the
#   IkdTreeConcurrency.RebuildVsMutatorRace stress now runs TSan-clean with
#   no suppressions (pre-fix it reports ~200 races), so any regression fails.
